## 📌 Executive Summary & Problem Statement

India's national steel production relies heavily on the import of **15 to 20 Million Tonnes of metallurgical coking coal annually** from overseas origins including Australia (Hay Point, Newcastle), Russia (Taman, Vostochny), the USA (Baltimore, Hampton Roads), Mozambique (Nacala), and Indonesia (Kalimantan).

### The Challenge:
1. **Extreme Freight Market Volatility**: Unpredictable fluctuations in the Baltic Dry Index (BDI) and marine bunker fuel (VLSFO) prices create severe budget variances.
2. **Strict Port & Riverine Draft Constraints**: Major discharge terminals possess vastly differing physical limits — from shallow riverine tidal drafts like **Haldia (8.5m max draft)** to deepwater private terminals like **Gangavaram (18.2m max draft)** and **Paradip (16.5m)**. Infeasible vessel chartering risks catastrophic grounding or Under-Keel Clearance (UKC) breaches.
3. **Demurrage Penalties & Congestion**: High port congestion (4.5 to 4.8 days average wait at Paradip/Haldia) results in **$35M–$60M+ in annual laytime demurrage liabilities**.

## 🌟 Core System Capabilities

### 1. 🤖 Predictive Freight Intelligence (XGBoost Regressor)
- **Model Performance**: $R^2 = 92.01\%$, $\text{RMSE} = \$1.42/\text{MT}$, $\text{MAE} = \$1.08/\text{MT}$.
- **Feature Engineering**: Multi-variable regression incorporating Baltic Dry Index (BDI), Very Low Sulfur Fuel Oil (VLSFO), voyage nautical distance, vessel deadweight, and seasonal Southwest Monsoon disruptions.

### 2. ⚓ Dual-Terminal Waterline Feasibility Gatekeeper
- Automatically validates vessel physical dimensions (Draft, LOA, Beam, DWT) against berth specifications at both loading and discharge ports.
- Enforces strict safety rules (e.g., blocking Capesize and Panamax at Haldia Dock Complex to protect estuarine river drafts).

### 3. ⚙️ Prescriptive Fleet Optimization (PuLP MILP Solver)
- Formulates a **Mixed-Integer Linear Program (MILP)** solved via the CBC solver in $<50\text{ ms}$:
  $$\min \sum_{v} n_v \cdot \text{Capacity}_v \cdot \text{FreightRate}_{\text{pred}} \cdot (1 - \text{Discount}_v)$$
- Evaluates 4 standard dry-bulk shipping classes:
  - **Capesize (170,000 MT DWT | 17.5m Draft)**: 15% Volume Discount
  - **Panamax (75,000 MT DWT | 13.5m Draft)**: 10% Volume Discount
  - **Supramax (55,000 MT DWT | 11.5m Draft)**: 5% Volume Discount
  - **Handysize (35,000 MT DWT | 8.5m Draft)**: Baseline Rate (0% Discount)

### 4. ⏱️ Demurrage Risk Radar & Deepwater Diversion Arbitrage
- Computes contractual laytime vs. actual port turnaround times.
- Quantifies financial savings generated by diverting draft-constrained or congested shipments to **Gangavaram Port (1.1-day turnaround)**, yielding **up to $78,000 net savings per voyage**.

### 5. 🧠 Logistics AI Copilot
- Context-aware natural language assistant providing instant route analysis, port intelligence, and trade lane comparisons (e.g., evaluating Russian coal FOB discounts vs. Australian corridors).

## ⚡ Quickstart & Local Setup

### Prerequisites
- **Node.js**: v18+ (v20+ recommended)
- **Python**: 3.9+

### 1. Clone the Repository
```bash
git clone https://github.com/siyamgit8/Marivance.git
cd Marivance
```

### 2. Install Dependencies
```bash
# Install Node.js frontend & backend packages
npm install

# (Optional) Install Python ML & Optimization packages
pip install -r requirements.txt
```

### 3. Run the Development Server
```bash
npm run dev
```
- **Frontend App**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:5000](http://localhost:5000)

### 4. Run the MILP Optimization Test Suite
```bash
python optimization_engine.py
```

### 5. Launch Streamlit Executive Command Center (Optional)
```bash
streamlit run dashboard.py
```
